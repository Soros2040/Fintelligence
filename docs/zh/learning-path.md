# 学习路径

[首页](../../README_zh.md) · [English](../en/learning-path.md)

学习目标是把一次实验解释到这样的程度：另一位参与者能够检查数据、复现变换，并对结论提出有依据的质疑。

## 前置知识

| 概念 | 需要具备的能力 | 准备任务 |
|---|---|---|
| Python 与 pandas | 阅读函数、对齐 MultiIndex | 构造两天、三只股票的数据表 |
| 统计 | 计算均值、标准差、相关系数 | 完成案例一的 IC 例子 |
| 时序评估 | 区分拟合区间和评估区间 | 画出训练、验证、测试时间轴 |
| 网页请求流程 | 区分界面事件与服务端工具调用 | 从 `sendMessage` 找到 `thread.submit` |
| 研究工程 | 记录版本和失败运行 | 完成一份实验凭据 |

了解 LangGraph、Qlib 或上下文 Bandit 会有帮助，但不是阅读门槛。两个案例都先解释数据结构，再使用相应概念。

## 建议顺序

1. **熟悉系统，30–45 分钟。** 阅读[架构](architecture.md)，找到前端流客户端、后端图注册及工具加载器，交付五步请求追踪。
2. **理解基线，60–90 分钟。** 完成[案例一](case-01-task-to-backtest.md)和两道练习，交付指标口径表及固定时间划分。
3. **理解因子，60–90 分钟。** 完成[案例二](case-02-factor-lifecycle.md)，交付因子节点、父子关系、检索计算与准入判断。
4. **配置与运行。** 在独立环境中按照[运行指南](run-guide.md)先检查导入和配置；开始调用模型前记录准确命令及依赖版本。
5. **参与贡献。** 选择[路线图](roadmap.md)中的一项，创建 Issue，再提交一个附证据、可审阅的修改。

## 一份能够支撑结论的研究记录

先写问题与比较对象，再记录数据覆盖、源码版本、实际特征、标签周期、时间划分、模型参数、成本和运行编号。如果不确定性或失败尝试影响结论，就解释其影响。只有图而没有指标定义，无法完成验收。

## 练习

你有一份正常结束的训练日志和一张高夏普比率截图，但特征标准化使用了全部日期。可以登记为时间外基线吗？

**答案。** 预处理可能使用了未来信息，存在数据泄漏问题。应在训练段拟合预处理，重新运行，并记录两个配置。应用运行成功证明执行完成；划分和变换审计才支撑时间外评估结论。
